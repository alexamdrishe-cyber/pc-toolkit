Вспомогательные сценарии для папки publish (она в git не попадает).
Скопируйте их в publish\ рядом со сборками:
  preview-setup.cmd   — запускает самый новый Setup с ключом /CURRENTUSER (без прав администратора, без службы);
  run-no-service.cmd  — запускает самую новую опубликованную сборку с ключом --no-service.
